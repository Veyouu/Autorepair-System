# AutoRepair System
## Required Library Installation Guide

### FlatLaf 3.5.4

Our system uses FlatLaf 3.5.4 to enhance the appearance of the Java Swing graphical user interface.

### Installation Instructions

Please follow these steps to install the required library:

1. Open the **AutoRepair System** project in IntelliJ IDEA.
2. Navigate to **File → Project Structure**.
3. Select **Modules**.
4. Open the **Dependencies** tab.
5. Click the **+ (Plus)** icon.
6. Select **Add Library** or **From Maven**, depending on your IntelliJ IDEA version.
7. Enter the following dependency:

   `com.formdev:flatlaf:3.5.4`

8. Click **Apply**.
9. Click **OK**.
10. Wait for IntelliJ IDEA to download and configure the library.

After completing these steps, the AutoRepair System should be ready to run.
